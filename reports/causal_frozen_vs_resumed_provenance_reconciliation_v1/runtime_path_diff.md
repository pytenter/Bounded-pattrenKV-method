# Runtime Path Diff

No CAUSAL algorithm or mixed-V runtime regression is supported by the A/B evidence. Under the same GPU, same model, same env, and same worker-level specification, 50a matches or slightly outperforms 8d at C2048/B1, C2048/B4, C4096/B1, C4096/B4, and C4096/B8.

The PatternKV-paper true-batch changes are reachable for canonical PatternKV-paper base-V2, but not for CAUSAL's mixed V4 selector path. The 4D centroid indexing change is benign for CAUSAL in the measured A/B.
