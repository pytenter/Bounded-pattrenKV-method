# Paper Number Decision

Use a newly reconciled same-harness rerun or regenerated paper-baseline table with the frozen allocator/memory lifecycle protocol explicitly restored for all methods. Do not use the stored 50a CAUSAL slow rows as primary CAUSAL numbers, because they do not reproduce in the current worker and the capacity loss is explained by allocator protocol drift. Do not silently mix frozen 8d CAUSAL numbers into the four-method table unless the same memory lifecycle protocol is applied to all methods.
