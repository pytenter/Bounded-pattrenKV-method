# Paper System Table and Figure Assembly V1

This directory contains paper-safe tables, figures, figure data, LaTeX assets, provenance, and claim audit artifacts assembled from the reconciled frozen system evidence.

- Run `python reports/paper_system_table_and_figure_assembly_v1/scripts/generate_system_tables.py` to regenerate tables and figure data.
- Run `python reports/paper_system_table_and_figure_assembly_v1/scripts/generate_system_figures.py` to regenerate PDF and PNG figures.
- Primary numbers trace to `reports/paper_baseline_system_comparison_v1_reconciled/final_gate.json`.
